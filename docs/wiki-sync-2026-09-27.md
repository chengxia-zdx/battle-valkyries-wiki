## 提取与显示修复

提取脚本扩展了篇章配置、额外注册的技能/皮肤、数组形式注册、莉莉动态灵魂技能及音量滑块的读取。所有篇章技能与皮肤奖励均校验引用；未加载内容不凭翻译键认定为已实现。

详情立绘、战场预览、皮肤大图改为按比例完整容纳，去除默认 figure 外边距，并可点击打开原图。新增内容保留中英文切换、角色搜索与技能目录筛选。若加载入口引用的配置文件尚未写出，提取器会输出明确警告并记录 `meta.missingConfigFiles`，不把缺失配置伪装成已提取。最终交付快照该列表为空。

## 验证范围

- `npm run check`：JavaScript 语法、目录计数、跨目录引用、奖励阶段、翻译和全部引用图片。
- `git diff --check`：补丁空白检查。
- 本地浏览器：中英文切换、角色搜索/切换、篇章展开、技能筛选、原图链接、详情图比例与资源加载；桌面和窄屏检查。

下次源码完成后运行 `npm run refresh` 并检查新增条目、加载状态和数值，再执行 `npm run check`。不要把此次快照的 78 个敌人或 8 个篇章当成永远固定的目标数。
